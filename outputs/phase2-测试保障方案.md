### 1.3 测试数据管理原则

1. **黄金数据集 golden cases 单一来源**：所有规则引擎期望值集中存放于 `packages/rule-engine/test/golden/*.json`，由产品主理人（政策口径）+ 技术负责人（实现口径）**双签**后才可变更；任何期望值变更必须走 PR 并附政策依据。
2. **三套数据环境隔离**：`local(fixtures)` / `staging(seed)` / `prod(no seed)`，禁止用生产数据回归。
3. **敏感财务数据脱敏**：测试数据中的统一社会信用代码、财务金额一律使用虚构值；`test-data` 库中禁止出现真实企业信息（用例 SEC-DATA-03 会扫描 fixtures 目录）。
4. **数据可复现**：每条 golden case 自带 `case_id + rulepack_version + 期望快照 SHA-256`，复算不一致即失败。
5. **不落库模式优先**：`storage_mode=local_only` 的测试数据默认只走浏览器端，接口测试仅回显，验证"不明文落库"（对应 E1/SEC-DATA-01）。
6. **幂等数据构造**：批量构造脚本统一用 `python3`（见附录 A），支持 `--seed` 固定随机种子，保证每次构造结果一致。

## 2. 规则引擎专项测试（最高风险，最高优先级）

> 被测对象：`@hitech/rule-engine`（纯 TS 包，零 IO、零框架依赖，依赖仅 `zod`）
> 硬性约束：浏览器端与服务端**同包同结果**（双端一致性）；引擎纯净性（禁 `Date` / `Math.random` / `fetch` / `prisma` / `fs`）
> 精度要求：**禁止浮点直比 0.35/0.25/0.15/0.05**，一律使用 `BigInt` 有理数或万分比整数比较（用例 RE-PREC-01~06）

### 2.1 成长性指标 · 16 组边界用例矩阵（8 场景 × 2 指标）

**算法口径**（PRD 附录 B.2 + 技术 §3.5.2，唯一实现口径）：

```
biz_years == 1                → g = 0            (edge: BIZ_YEARS_1)
biz_years == 2 : v1 <= 0      → g = 0            (edge: BIZ_YEARS_2_V1_ZERO)
                else          → g = v2/v1 − 1
biz_years >= 3 : v2 <= 0      → g = 0            (edge: V2_ZERO / BOTH_ZERO)
                v1 <= 0       → g = v3/v2 − 1    (edge: V1_ZERO)
                else          → g = ½(v2/v1 + v3/v2) − 1   (负增长 clamp 到 0，edge: NEGATIVE_CLAMPED)
```

**分档**：`≥35% → (9,10)`；`≥25% → (7,8)`；`≥15% → (5,6)`；`≥5% → (3,4)`；`>0 → (1,2)`；`≤0 → (0,0)`

**附加断言（每组均须校验）**：
1. `growth_rate` 以 `{num, den}` 有理数形式返回，禁止浮点；`num/den` 与期望值在 1e-12 容差内相等。
2. 该指标 `score_min = L`、`score_max = U`，且 `0 ≤ score_min ≤ score_max ≤ 10`。
3. 成长性大项 `total_min = score_min(净资产) + score_min(销售)`，`total_max` 同理，**上限 20 不得溢出**。
4. `edge_code` 严格等于表中值（`null` 场景不得返回任何 edge）。
5. 结果页/报告页需展示该 edge 对应的**边界提示文案**（PRD §7.7），文案与 edge 一一映射。

### 4.2 接口通用断言（每条用例必带）

1. HTTP 状态码与错误码符合 §4 基线；HTTP 4xx 时响应体必含 `{code, message, request_id}`。
2. 响应头：`X-Request-Id` 存在；`Cache-Control: no-store`（含财务数据的接口）。
3. 响应时间 P95 ≤800ms（性能用例 PERF-API-01 统一采集）。
4. 数据库断言：写操作后校验落库字段；`local_only` 模式**校验未落库**（SEC-DATA-01）。
5. 日志断言：本次请求日志中**不含**企业名/信用代码/财务明文（SEC-LOG-01）。
6. 契约断言：响应体通过 zod schema 校验，字段缺失或类型不符即失败。

## 9. 缺陷分级标准与质量门禁（量化）

### 9.1 缺陷分级

| 级别 | 定义 | 典型示例（本项目） | 修复时限 | 是否阻断发布 |

### A.1 golden 数据集构造（固定随机种子）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""构造规则引擎 golden 数据集（可复现）。用法:
   python3 tools/gen_golden.py --seed 20261008 --out packages/rule-engine/test/golden/cases.json
"""
import argparse, hashlib, json, random
from fractions import Fraction

BANDS = [(Fraction(35, 100), (9, 10)), (Fraction(25, 100), (7, 8)),
         (Fraction(15, 100), (5, 6)), (Fraction(5, 100), (3, 4)),
         (Fraction(0, 1), (1, 2))]


def band_of(g: Fraction):
    if g <= 0:
        return (0, 0), None
    for threshold, band in BANDS:
        if g >= threshold:
            return band, None
    return (0, 0), "NEGATIVE_CLAMPED"


def growth(v1, v2, v3, biz_years):
    """与 PRD 附录 B.2 / 技术研发 §3.5.2 完全一致的参考实现（有理数）"""
    if biz_years == 1:
        return Fraction(0), "BIZ_YEARS_1"
    if biz_years == 2:
        if v1 <= 0:
            return Fraction(0), "BIZ_YEARS_2_V1_ZERO"
        return Fraction(v2 - v1, v1), None
    if v2 <= 0:
        return Fraction(0), "BOTH_ZERO" if v1 <= 0 else "V2_ZERO"
    if v1 <= 0:
        g = Fraction(v3 - v2, v2)
        return (g, "V1_ZERO") if g > 0 else (Fraction(0), "NEGATIVE_CLAMPED")
    g = (Fraction(v2, v1) + Fraction(v3, v2)) / 2 - 1
    return (g, None) if g > 0 else (Fraction(0), "NEGATIVE_CLAMPED")


def make_case(cid, metric, v1, v2, v3, biz_years):
    g, edge = growth(v1, v2, v3, biz_years)
    band, clamp = band_of(g)
    if clamp:
        edge = clamp
    case = {
        "case_id": cid,
        "module": "growth",
        "input": {"metric": metric, "v1": v1, "v2": v2, "v3": v3, "biz_years": biz_years},
        "expect": {
            "growth_rate": {"num": str(g.numerator), "den": str(g.denominator)},
            "band": list(band), "score_min": band[0], "score_max": band[1],
            "edge_code": edge,
        },
        "rulepack_version": "1.0.0",
    }
    case["expect_sha256"] = hashlib.sha256(
        json.dumps(case["expect"], sort_keys=True, ensure_ascii=False).encode("utf-8")
    ).hexdigest()
    return case


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--seed", type=int, default=20261008)
    ap.add_argument("--out", default="cases.json")
    args = ap.parse_args()
    random.seed(args.seed)

    # 16 组基准矩阵（8 场景 × 2 指标）
    base = [
        ("3年正常", 1000, 1200, 1500, 3), ("3年v1=0", 0, 1000, 1500, 3),
        ("3年v2=0", 1000, 0, 1500, 3), ("3年v1=v2=0", 0, 0, 1500, 3),
        ("3年负增长", 1200, 1000, 900, 3), ("2年正常", 1000, 1300, 0, 2),
        ("2年v1=0", 0, 1300, 0, 2), ("1年", 0, 0, 0, 1),
    ]
    cases = []
    for i, (_, v1, v2, v3, by) in enumerate(base, start=1):
        for j, metric in enumerate(("net_asset", "revenue"), start=0):
            cases.append(make_case(f"RE-GR-{i * 2 - 1 + j:02d}", metric, v1, v2, v3, by))

    # 属性测试用例（固定种子，可复现）
    for k in range(500):
        v1 = random.randint(1, 10 ** 7)
        v2 = random.randint(0, 10 ** 7)
        v3 = random.randint(0, 10 ** 7)
        cases.append(make_case(f"RE-GR-PROP-{k:03d}", "net_asset", v1, v2, v3, 3))

    with open(args.out, "w", encoding="utf-8") as f:
        json.dump(cases, f, ensure_ascii=False, indent=2)
    print(f"generated {len(cases)} cases -> {args.out}")


if __name__ == "__main__":
    main()
```

### A.2 PDF 中文与字体嵌入自动校验

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""校验导出 PDF：中文无乱码 + 字体嵌入 + A4 + 页数。依赖: pdftotext / pdffonts (poppler-utils)
   用法: python3 tools/check_pdf.py report.pdf --expect-text 免责声明 --pages-min 7
"""
import argparse, re, subprocess, sys


def sh(cmd):
    return subprocess.run(cmd, capture_output=True, text=True, encoding="utf-8").stdout


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("pdf")
    ap.add_argument("--expect-text", nargs="*", default=["免责声明"])
    ap.add_argument("--pages-min", type=int, default=7)
    args = ap.parse_args()
    errors = []

    text = sh(["pdftotext", args.pdf, "-"])
    # 1) 中文乱码检测：替换字符 U+FFFD 与典型乱码字符
    if "�" in text:
        errors.append("检测到 U+FFFD 替换字符（乱码/字形缺失）")
    if re.search(r"锟斤拷|\?\?\?\?", text):
        errors.append("检测到典型编码乱码片段")

    # 2) 关键字齐备（免责声明等）
    for kw in args.expect_text:
        if kw not in text:
            errors.append(f"缺少关键字: {kw}")

    # 3) 字体嵌入
    fonts = sh(["pdffonts", args.pdf])
    if "yes" not in fonts:
        errors.append("存在未嵌入字体（emb != yes）")

    # 4) 页数与页面尺寸
    info = sh(["pdfinfo", args.pdf])
    pages = int(re.search(r"Pages:\s+(\d+)", info).group(1))
    if pages < args.pages_min:
        errors.append(f"页数不足: {pages} < {args.pages_min}")
    size = re.search(r"Page size:\s+([\d.]+) x ([\d.]+) pts", info)
    if size:
        w, h = float(size.group(1)), float(size.group(2))
        if not (590 <= w <= 600 and 835 <= h <= 850):  # A4 210x297mm ≈ 595x842pt
            errors.append(f"页面尺寸非 A4: {w}x{h}pt")

    print("\n".join(errors) if errors else "PDF CHECK PASS")
    sys.exit(1 if errors else 0)


if __name__ == "__main__":
    main()
```

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""扫描日志/埋点是否含敏感字段。用法: python3 tools/scan_sensitive.py logs/*.log
   命中即失败（门禁 G-14）。"""
import argparse, re, sys

PATTERNS = {
    "统一社会信用代码": r"91\d{16}[0-9A-HJ-NPQRTUWXY]",
    "企业全称疑似": r"(有限公司|股份有限公司)",
    "金额明文(>6位)": r"\b\d{7,}(?:\.\d{1,2})?\b",
    "快照token": r"[A-Za-z0-9_-]{32,}",
    "手机号": r"1[3-9]\d{9}",
    "邮箱": r"[\w.+-]+@[\w-]+\.[\w.]+",
}


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("files", nargs="+")
    args = ap.parse_args()
    hits = {k: [] for k in PATTERNS}
    for path in args.files:
        with open(path, encoding="utf-8", errors="ignore") as f:
            for lineno, line in enumerate(f, 1):
                for name, pat in PATTERNS.items():
                    if re.search(pat, line):
                        hits[name].append(f"{path}:{lineno}")
    total = sum(len(v) for v in hits.values())
    for name, lst in hits.items():
        if lst:
            print(f"[HIT] {name}: {len(lst)} 处，示例 {lst[:3]}")
    print(f"SENSITIVE SCAN {'FAIL' if total else 'PASS'} (total={total})")
    sys.exit(1 if total else 0)


if __name__ == "__main__":
    main()

### A.4 双端一致性比对（CI 内调用，Node/jsdom 两份输出比对）

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""比对 Node 与 jsdom 两份规则引擎输出（JSON），逐字节比对。
   用法: python3 tools/parity_diff.py out.node.json out.jsdom.json"""
import hashlib, json, sys


def load(p):
    with open(p, encoding="utf-8") as f:
        return json.load(f)


def norm(o):
    return json.dumps(o, sort_keys=True, ensure_ascii=False, separators=(",", ":"))


def main():
    a, b = load(sys.argv[1]), load(sys.argv[2])
    if len(a) != len(b):
        print(f"PARITY FAIL: 用例数不同 {len(a)} vs {len(b)}")
        sys.exit(1)
    for i, (x, y) in enumerate(zip(a, b)):
        if norm(x) != norm(y):
            print(f"PARITY FAIL @ index {i} case_id={x.get('case_id')}")
            print("  node :", norm(x)[:400])
            print("  jsdom:", norm(y)[:400])
            sys.exit(1)
    print(f"PARITY PASS ({len(a)} cases, sha256="
          f"{hashlib.sha256(norm(a).encode('utf-8')).hexdigest()[:16]}...)")


if __name__ == "__main__":
